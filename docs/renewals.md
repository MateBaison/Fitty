# Renovaciones y fechas a recordar

Datos comprobados el 26 de noviembre de 2026.

| Qué                        | Fecha                                                       | Costo y forma                                 | Dónde                                           |
| -------------------------- | ----------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------- |
| Dominio `fitty.uy`         | vence el **11 de octubre de 2027** (cada año)               | precio según Netuy; comprobar si renueva solo | panel de Netuy                                  |
| Apple Developer Program    | se renueva el **28 de octubre de 2027** (cada año)          | 99 € por año, renovación automática activada  | <https://developer.apple.com/account>           |
| Clave de ingreso con Apple | caduca cada 6 meses; GitHub la renueva el día 1 de cada mes | gratis, automático                            | GitHub → Actions → «Renew Apple sign-in secret» |
| Copia de seguridad         | semanal, en la Mac                                          | gratis                                        | [database-backup.md](database-backup.md)        |

- Si el dominio vence, dejan de funcionar la web, el inicio de sesión de la app y el correo de soporte.
- Si vence Apple Developer, la app se retira de App Store.
- Revisá una vez por mes que la renovación de la clave de Apple figure en verde. GitHub desactiva las tareas programadas de un repositorio público tras 60 días sin actividad.
