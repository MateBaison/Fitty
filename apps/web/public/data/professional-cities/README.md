# Professional directory locations

Source: [GeoNames](https://www.geonames.org/), downloaded 2026-10-18.
[countryInfo.txt](https://download.geonames.org/export/dump/countryInfo.txt) [admin1CodesASCII.txt](https://download.geonames.org/export/dump/admin1CodesASCII.txt) and [cities500.zip](https://download.geonames.org/export/dump/cities500.zip).
License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Country records retain ISO code and source name. City records are [GeoNames ID, name, first-level administrative name], grouped by country and sorted by name. Coordinates and other columns omitted. This is a snapshot of the cities500 dataset (populated places over 500 inhabitants and administrative seats), not every settlement worldwide. Country names are localized using Intl.DisplayNames. City IDs distinguish duplicate names.
